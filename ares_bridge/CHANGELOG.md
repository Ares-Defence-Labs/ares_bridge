## 0.0.1

* Add the platform-neutral USB host/accessory lifecycle API.
* Add bidirectional single-file and batch transfer requests.
* Add broadcast connection, progress, completion, received-file, and failure
  streams.
* Define the Flutter method/event channel contract for native backends.
* Register the contract on Android, macOS, Windows, Linux, iOS, and web.
* Add Android Open Accessory attach/permission/session handling and
  checksum-verified bidirectional file framing.
* Add platform capability reporting and explicit unsupported-platform errors.
